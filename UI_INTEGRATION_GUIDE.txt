================================================================================
  NSE MUTUAL FUND API — UI INTEGRATION GUIDE (CUSTOMER ENDPOINTS)
  Base URL : http://127.0.0.1:8000/api/v1
  Auth     : Bearer <nse_token>  (obtained from POST /auth/login)
================================================================================

IMPORTANT RULES FOR UI
-----------------------
1. Call POST /auth/login first. Save the "nse_token" from the response.
2. Send  Authorization: Bearer <nse_token>  on every subsequent request.
3. client_code is NEVER sent by the UI for order/SIP/XSIP — the backend
   auto-injects it from the database after verifying UCC registration.
4. client_code IS required only for /mf/payments/purchase and
   /mf/payments/upi-status (use the value returned by /auth/login).
5. euin_number and euin_declaration are also auto-injected — do not send them.


================================================================================
STEP 1 — LOGIN
================================================================================

POST /auth/login
----------------
Request:
  {
    "email": "customer@example.com",
    "password": "Password@123"
  }

Response (200):
  {
    "success": true,
    "message": "Login successful",
    "lendrix_access_token": "<lendrix_jwt>",
    "lendrix_refresh_token": "<refresh_jwt>",
    "nse_token": "<nse_jwt>",          <-- SAVE THIS, use as Bearer token
    "sso_token": "<sso_jwt>",
    "user": {
      "id": "<lendrix_uuid>",
      "email": "customer@example.com",
      "firstName": "John",
      "lastName": "Doe"
    },
    "nse": {
      "client_codes": ["LVMF00001"],   <-- empty [] if not yet UCC registered
      "nse_registered": true,
      "registration_status": "registered"
    },
    "ucc_details": [                   <-- null if not yet UCC registered
      {
        "client_code": "LVMF00001",
        "primary_holder_first_name": "JOHN",
        "primary_holder_pan": "ABCDE1234F",
        "email": "customer@example.com",
        "indian_mobile_no": "9999999999",
        "reg_status": "REG_SUCCESS"
      }
    ]
  }

UI Logic:
  - If nse.nse_registered = false  --> show UCC Registration form (Step 3)
  - If nse.nse_registered = true   --> go directly to dashboard (Step 5+)

STEP 2 — CHECK ONBOARDING STATUS
================================================================================

GET /mf/onboarding/status
--------------------------
Headers: Authorization: Bearer <nse_token>

Response (200):
  {
    "authenticated": true,
    "lendrix_uuid": "<uuid>",
    "has_nse_account": false,
    "linking_required": true,
    "client_codes": [],
    "ucc_status": "not_started",
    "onboarding_status": "not_started",
    "next_action": "start_registration",
    "readiness_checks": {
      "lendrix_kyc": "unknown",
      "fatca": "unknown",
      "bank": "unknown",
      "mandate": "unknown"
    }
  }

ucc_status values and UI action:
  "not_started"              --> show UCC registration form
  "registration_in_progress" --> show "Processing..." spinner
  "pending_confirmation"     --> show "Awaiting NSE confirmation"
  "registered"               --> show dashboard
  "rejected"                 --> show error + retry option
  "linking_required"         --> show "Contact support"
  "unknown"                  --> show "Awaiting confirmation"

next_action values:
  "start_registration"       --> render UCC form
  "await_confirmation"       --> show pending state
  "correct_registration"     --> show form with error message
  "link_existing_account"    --> show support contact
  "open_dashboard"           --> redirect to dashboard

STEP 4 — CUSTOMER REGISTRATION STATUS (quick check)
================================================================================

GET /customer/registration/status
-----------------------------------
Headers: Authorization: Bearer <nse_token>

Response (200):
  {
    "authenticated": true,
    "registration_status": "registered",
    "client_codes": ["LVMF00001"],
    "attempt_status": "registered",
    "euin": "E123456"
  }

registration_status values:
  "registered"       --> has verified UCC, show dashboard
  "pending"          --> NSE processing, show spinner
  "failed"           --> NSE rejected, show retry
  "unlinked"         --> no UCC attempt yet, show registration form
  "linking_required" --> contact support
  "unknown"          --> show pending state

STEP 5 — FULL MF ONBOARDING PROGRESS (6-step tracker)
================================================================================

GET /customer/onboarding/status
--------------------------------
Headers: Authorization: Bearer <nse_token>

Response (200):
  {
    "authenticated": true,
    "onboarding_complete": false,
    "steps": {
      "ucc":      { "done": true,  "status": "registered",    "client_codes": ["LVMF00001"] },
      "ekyc":     { "done": true,  "status": "KYC VALIDATED", "verified": true },
      "aof":      { "done": false, "status": "not_submitted",  "records_found": 0 },
      "elog":     { "done": false, "status": "not_submitted",  "records_found": 0 },
      "mandate":  { "done": false, "status": "not_registered", "mandate_count": 0 },
      "nominees": { "done": true,  "status": "added",          "nominee_count": 1 }
    }
  }

UI Logic:
  - Render a 6-step progress bar using steps[*].done (true = green, false = pending)
  - onboarding_complete = true  --> show "Ready to Invest" banner
  - Each step.done = false      --> highlight that step as the next action


================================================================================
STEP 6 — FETCH UCC PROFILE (view registered details)
================================================================================

GET /ucc/fetch/{client_code}
-----------------------------
Headers: Authorization: Bearer <nse_token>
Example : GET /ucc/fetch/LVMF00001

Response (200): Full UCC profile including name, PAN, bank details,
                address, nominees, reg_status, reg_id

Error (403): client_code does not belong to this token
Error (404): No UCC record found for this client_code

STEP 7 — PLACE A LUMPSUM ORDER
================================================================================

POST /mf/order/entry
---------------------
Headers: Authorization: Bearer <nse_token>
NOTE: Do NOT send client_code, euin_number, euin_declaration — auto-injected.

Request:
  {
    "transaction_details": [
      {
        "scheme_code": "INF204K01I28",
        "trxn_type": "P",
        "buy_sell_type": "FRESH",
        "demat_physical": "P",
        "order_amount": "5000",
        "kyc_flag": "Y",
        "euin_declaration": "N",
        "folio_no": "",
        "remarks": ""
      }
    ]
  }

trxn_type values:
  "P"  --> Purchase (Buy)
  "R"  --> Redemption (Sell)
  "SP" --> Switch Purchase
  "SR" --> Switch Redemption

buy_sell_type values:
  "FRESH"      --> New folio
  "ADDITIONAL" --> Existing folio

demat_physical:
  "P" Physical   "D" Demat

Response (200):
  {
    "transaction_details": [
      {
        "trxn_order_id": "ORD123456",
        "client_code": "LVMF00001",
        "scheme_code": "INF204K01I28",
        "trxn_status": "0",
        "trxn_remark": "Order Accepted"
      }
    ]
  }

Error (403 — UCC not registered):
  {
    "detail": {
      "code": "NSE_REGISTRATION_REQUIRED",
      "message": "No verified NSE client code found. Please complete NSE registration."
    }
  }

STEP 10 — PAYMENT (after placing order)
================================================================================

POST /mf/payments/purchase
---------------------------
Headers: Authorization: Bearer <nse_token>
NOTE: client_code IS required here — use value from login response or
      /customer/registration/status.

Request (UPI):
  {
    "payment_mode": "UPI",
    "client_code": "LVMF00001",
    "order_ids": "ORD123456",
    "vpa": "customer@upi",
    "callback_url": "https://yourapp.com/payment/callback"
  }

Request (Net Banking):
  {
    "payment_mode": "NET",
    "client_code": "LVMF00001",
    "order_ids": "ORD123456",
    "bank_account_no": "1234567890",
    "ifsc": "HDFC0001234"
  }

Request (Mandate):
  {
    "payment_mode": "MANDATE",
    "client_code": "LVMF00001",
    "order_ids": "ORD123456",
    "mandate_id": "MANDATE001"
  }

payment_mode values:
  "UPI"     --> vpa required
  "NET"     --> bank_account_no + ifsc required
  "MANDATE" --> mandate_id required
  "CHEQUE"  --> cheque_no + cheque_date required
  "NEFT"    --> neft_rtgs_utr_no required

Response (200):
  {
    "payment_mode": "UPI",
    "client_code": "LVMF00001",
    "order_ids": "ORD123456",
    "status": "0",
    "short_url": "https://pay.upi/xyz",
    "remark": "Payment initiated"
  }

SCHEME CATALOGUE (no UCC required)

GET /customer/schemes
----------------------
Headers: Authorization: Bearer <nse_token>

Use for : Populating scheme search / autocomplete dropdown in the UI
Cache   : Response can be cached for the session (changes infrequently)

ERROR CODES REFERENCE
================================================================================

HTTP  Code                       Meaning / UI Action
----  -------------------------  -----------------------------------------------
400   -                          Bad request — show field validation error
401   -                          Token expired — redirect to login
403   NSE_REGISTRATION_REQUIRED  UCC not done — redirect to registration form
403   MULTIPLE_CLIENT_CODES      Multiple accounts — contact support
409   -                          Duplicate/conflict — check onboarding status
422   -                          Missing required field — show form error
500   -                          Server error — show generic retry message
503   -                          NSE/Lendrix service down — show retry later
