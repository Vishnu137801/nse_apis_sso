================================================================================
  NSE MUTUAL FUND — CUSTOMER API INTEGRATION
  Base URL : http://127.0.0.1:8000/api/v1
  Total    : 12 APIs
================================================================================

AUTH HEADER (all APIs except login):
  Authorization: Bearer <nse_token>

CLIENT CODE RULE:
  - NEVER send client_code for order / SIP / XSIP — backend auto-injects it
  - client_code is auto-injected ONLY after UCC is registered (REG_SUCCESS)
  - If UCC not done → 403 NSE_REGISTRATION_REQUIRED

================================================================================
API 1 — LOGIN
================================================================================

POST /auth/login

Request:
  {
    "email": "customer@example.com",
    "password": "Password@123"
  }

Response (200):
  {
    "success": true,
    "message": "Login successful",
    "nse_token": "<JWT>",               <-- save this, send as Bearer on all APIs
    "lendrix_access_token": "<JWT>",
    "lendrix_refresh_token": "<JWT>",

      "email": "customer@example.com",

      "lastName": "Doe",
      "phone": "9999999999"
    },
    "nse": {
      "client_codes": ["LVMF00001"],    <-- [] if not yet UCC registered
      "nse_registered": true,
      "registration_status": "registered"
    },
    "ucc_details": [                    <-- null if not yet UCC registered
      {
        "client_code": "LVMF00001",
        "primary_holder_first_name": "JOHN",
        "primary_holder_last_name": "DOE",
        "primary_holder_pan": "ABCDE1234F",
        "email": "customer@example.com",
        "indian_mobile_no": "9999999999",
        "address_1": "123 Main St",

  if nse.nse_registered = false  --> go to API 3 (UCC Register)
  if nse.nse_registered = true   --> go to API 5 (Onboarding Status)

API 2 — ONBOARDING STATUS (simple)
================================================================================

GET /mf/onboarding/status
Authorization: Bearer <nse_token>

Response (200):
  {
    "authenticated": true,
    "lendrix_uuid": "021bd4fe-f07f-4b39-8e17-b70c786f4ed8",
    "has_nse_account": false,
    "linking_required": true,
    "client_codes": [],
    "ucc_status": "not_started",
    "onboarding_status": "not_started",
    "next_action": "start_registration",
    "readiness_checks": {
      "lendrix_kyc": "unknown",
      "fatca": "unknown",
      "bank": "unknown",
      "mandate": "unknown"
    }
  }

ucc_status → UI action:
  "not_started"              --> show UCC form
  "registration_in_progress" --> show spinner
  "pending_confirmation"     --> show "Awaiting NSE confirmation"
  "registered"               --> show dashboard
  "rejected"                 --> show error + retry
  "linking_required"         --> show "Contact support"

next_action → UI action:
  "start_registration"       --> render UCC form
  "await_confirmation"       --> show pending state
  "correct_registration"     --> show form with error
  "link_existing_account"    --> show support contact
  "open_dashboard"           --> redirect to dashboard

API 4 — REGISTRATION STATUS (quick check)
================================================================================

GET /customer/registration/status
Authorization: Bearer <nse_token>

Response (200):
  {
    "authenticated": true,
    "registration_status": "registered",
    "client_codes": ["LVMF00001"],
    "attempt_status": "registered",
    "euin": "E123456"
  }

registration_status values:
  "registered"       --> UCC done, show dashboard
  "pending"          --> NSE processing, show spinner
  "failed"           --> NSE rejected, show retry
  "unlinked"         --> no attempt yet, show UCC form
  "linking_required" --> contact support
  "unknown"          --> show pending state

API 8 — PLACE ORDER (Lumpsum Buy / Sell)
================================================================================

POST /mf/order/entry
Authorization: Bearer <nse_token>

NOTE: Do NOT send client_code / euin_number / euin_declaration

Request:
  {
    "transaction_details": [
      {
        "scheme_code": "INF204K01I28",
        "trxn_type": "P",
        "buy_sell_type": "FRESH",
        "demat_physical": "P",
        "order_amount": "5000",
        "kyc_flag": "Y",
        "euin_declaration": "N",
        "folio_no": "",
        "remarks": ""

trxn_type  : "P"=Purchase  "R"=Redemption  "SP"=Switch Purchase  "SR"=Switch Redeem

demat      : "P"=Physical  "D"=Demat

  {
    "transaction_details": [
      {
        "trxn_order_id": "ORD123456",
        "client_code": "LVMF00001",

    "detail": {

      "message": "No verified NSE client code found."

  }

API 11 — PURCHASE PAYMENT
================================================================================

POST /mf/payments/purchase
Authorization: Bearer <nse_token>

NOTE: client_code is optional — auto-injected from session if not sent

Request (UPI):
  {
    "payment_mode": "UPI",
    "order_ids": "ORD123456",
    "vpa": "customer@upi",
    "callback_url": "https://yourapp.com/payment/callback"
  }

Request (Net Banking):
  {
    "payment_mode": "NET",
    "order_ids": "ORD123456",
    "bank_account_no": "1234567890",
    "ifsc": "HDFC0001234"
  }

Request (Mandate):
  {
    "payment_mode": "MANDATE",
    "order_ids": "ORD123456",
    "mandate_id": "MANDATE001"
  }

Request (Cheque):
  {
    "payment_mode": "CHEQUE",
    "order_ids": "ORD123456",
    "cheque_no": "123456",
    "cheque_date": "01/01/2026"
  }

Request (NEFT):
  {
    "payment_mode": "NEFT",
    "order_ids": "ORD123456",
    "neft_rtgs_utr_no": "UTR123456"
  }

payment_mode values:
  "UPI"     → vpa required
  "NET"     → bank_account_no + ifsc required
  "MANDATE" → mandate_id required
  "CHEQUE"  → cheque_no + cheque_date required
  "NEFT"    → neft_rtgs_utr_no required

Response (200):
  {
    "payment_mode": "UPI",
    "client_code": "LVMF00001",
    "order_ids": "ORD123456",
    "status": "0",
    "short_url": "https://pay.upi/xyz",
    "basket_id": "BASKET001",
    "remark": "Payment initiated"
  }

Errors:
  403 NSE_REGISTRATION_REQUIRED → UCC not done
  403 → order_ids don't belong to this customer

================================================================================
ERROR CODES
================================================================================

  HTTP  Code                       UI Action
  ----  -------------------------  -------------------------------------------
  400   -                          Show field validation error
  401   -                          Token expired → redirect to login
  403   NSE_REGISTRATION_REQUIRED  UCC not done → show registration form
  403   MULTIPLE_CLIENT_CODES      Contact support
  403   -                          Order/payment not owned by this customer
  409   -                          Duplicate → check onboarding status
  422   -                          Missing required field → show form error
  500   -                          Server error → show retry
  503   -                          NSE down → show "try again later"
