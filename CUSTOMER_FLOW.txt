1. LOGIN
================================================================================

POST /api/v1/auth/login

Request:
{
  "email": "customer@example.com",
  "password": "yourpassword"
}

Response:
{
  "success": true,
  "message": "Login successful",
  "nse_token": "<JWT — store this and send as Bearer token>",
  "lendrix_access_token": "<lendrix token>",
  "lendrix_refresh_token": "<lendrix refresh token>",
  "user": {
    "id": "<lendrix_uuid>",
    "email": "customer@example.com",
    "firstName": "John",
    "lastName": "Doe",
    "phone": "9999999999"
  },
  "nse": {
    "client_codes": ["LVMF00001"],
    "nse_registered": true,
    "registration_status": "registered"
  },
  "ucc_details": [
    {
      "client_code": "LVMF00001",
      "primary_holder_first_name": "John",
      "primary_holder_pan": "ABCDE1234F",
      "email": "customer@example.com",
      "reg_status": "REG_SUCCESS"
    }
  ]
}

Flow:
  → Proxied to Lendrix auth server
  → lendrix_uuid extracted from Lendrix response
  → DB queried for client_codes linked to lendrix_uuid
  → nse_token JWT minted with lendrix_uuid + client_codes
  → Customer profile upserted in DB
  → UCC details fetched from DB and returned

================================================================================
2. CHECK REGISTRATION STATUS
================================================================================

GET /api/v1/customer/registration/status
Headers: Authorization: Bearer <nse_token>

Response:
{
  "registration_status": "registered",   // unlinked | pending | failed | registered
  "client_codes": ["LVMF00001"],
  "attempt_status": "registered",
  "euin": "E656590"
}

registration_status values:
  "unlinked"         → Customer has no NSE account — show info screen
  "pending"          → Registration submitted, waiting for NSE confirmation
  "failed"           → Registration rejected by NSE
  "linking_required" → Account exists but needs manual linking
  "registered"       → Fully registered — proceed to onboarding/status

Flow:
  → nse_token verified → lendrix_uuid extracted
  → DB queried: lendrix_user_nse_mapping JOIN ucc_registrations
    (only returns codes with reg_status IN REG_SUCCESS, S)
  → Latest CustomerUccAttempt fetched for status

3. CHECK ONBOARDING STATUS (6 STEPS)
================================================================================

GET /api/v1/customer/onboarding/status
Headers: Authorization: Bearer <nse_token>

Response:
{
  "authenticated": true,
  "onboarding_complete": false,
  "steps": {
    "ucc": {
      "done": true,
      "status": "registered",
      "client_codes": ["LVMF00001"]
    },
    "ekyc": {
      "done": true,
      "status": "KYC VALIDATED",
      "verified": true
    },
    "aof": {
      "done": false,
      "status": "not_submitted",
      "records_found": 0
    },
    "elog": {
      "done": false,
      "status": "not_submitted",
      "records_found": 0
    },
    "mandate": {
      "done": false,
      "status": "not_registered",
      "mandate_count": 0
    },
    "nominees": {
      "done": false,
      "status": "not_added",
      "nominee_count": 0
    }
  }
}

Flow:
  → nse_token verified → client_code extracted
  → 6 NSE report APIs called in PARALLEL:
      CLIENT_KYC_REPORT        → ekyc step
      AOF_IMAGE_UPLOAD_REPORT  → aof step
      ELOG_UPLOAD_REPORT       → elog step
      MANDATE_STATUS           → mandate step
      client_master_report     → nominees step
      DB client_codes check    → ucc step
  → Response cached per customer for 60 seconds

UI Action per step:
  ucc.done = false      → Show "Contact support" (admin registers UCC)
  ekyc.done = false     → Call POST /mf/ekyc/register or /mf/kyc/fresh-register
  aof.done = false      → Call POST /mf/aof/image-upload
  elog.done = false     → Call POST /mf/elog/upload
  mandate.done = false  → Call POST /mf/mandate/register
  nominees.done = false → Call POST /mf/nft/nominee

================================================================================
COMPLETE CUSTOMER JOURNEY
================================================================================

STEP 1: Login
  POST /auth/login
  → Store nse_token from response

STEP 2: Check Registration
  GET /customer/registration/status
  → "registered"       → Go to Step 3
  → "unlinked"         → Contact support (admin registers UCC)
  → "pending"          → Show "Registration in progress" screen
  → "failed"           → Show error, contact support

STEP 3: Check Onboarding
  GET /customer/onboarding/status
  → Check each step:

    ucc.done = false      → Contact support
    ekyc.done = false     → POST /mf/ekyc/register
                            or POST /mf/kyc/fresh-register
    aof.done = false      → POST /mf/aof/image-upload
    elog.done = false     → POST /mf/elog/upload
    mandate.done = false  → POST /mf/mandate/register
    nominees.done = false → POST /mf/nft/nominee
    fatca pending         → POST /mf/fatca/upload

STEP 4: After All Steps Done
  → onboarding_complete = true
  → Customer is fully onboarded
  → GET /customer/schemes to browse mutual funds

STEP 5: Update Details Anytime
  Change bank account  → POST /mf/nft/change-of-bank
  Change contact       → POST /mf/nft/change-of-contact
  Update nominee       → POST /mf/nft/nominee

================================================================================
DB TABLES UPDATED BY CUSTOMER APIS
================================================================================

API                          | DB Table
-----------------------------|----------------------
POST /mf/mandate/register    | mandate_registrations
POST /mf/aof/image-upload    | aof_image_uploads
POST /mf/elog/upload         | elog_uploads

EKYC, KYC fresh, NFT APIs → No DB save (NSE owns that data)

================================================================================
ERROR CODES
================================================================================

401 Unauthorized     → nse_token missing, expired or invalid → Re-login
403 Forbidden        → No verified client_code found → UCC not registered
                       or PAN not owned by this customer
502 Bad Gateway      → Cannot connect to NSE
504 Gateway Timeout  → NSE request timed out
422 Unprocessable    → Missing required fields in request body
500 Internal Error   → NSE accepted but DB save failed — do not retry
