[ ] POST /auth/sso/generate-code   (requires customer Bearer token)
    curl -X POST http://localhost:5000/auth/sso/generate-code \
      -H "Authorization: Bearer <TOKEN>"
    EXPECT: 200 { "success": true, "code": "...", "expires_in": 60 }
    EXPECT if no token: 401

[ ] POST /auth/sso/verify-code   (requires service secret in Authorization)
    curl -X POST http://localhost:5000/auth/sso/verify-code \
      -H "Authorization: Bearer <SERVICE_SECRET>" \
      -H "Content-Type: application/json" \
      -d '{"code":"<SSO_CODE>"}'
    EXPECT: 200 { "success": true, "customer": { "lendrix_uuid": "..." } }
    EXPECT if bad code: 400 { "code": "INVALID_SSO_CODE" }
    EXPECT if no secret: 401

HOW TO SWITCH SCENARIO WITHOUT RESTARTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The frontend calls /api/v1/customer/onboarding/status with no query param.
To test a specific scenario, temporarily edit nseSsoSession.ts:

  Change:  nseApiFetch('/customer/onboarding/status')
  To:      nseApiFetch('/customer/onboarding/status?scenario=complete')

Revert after testing.
